## Список требований

### Требования к безопасности


- Должно использоваться принудительное https шифрование.
- Настроенный firewall.
- База данных с биометрией и номерами автомобилей должна быть зашифрована
- Персональные данные должны токенизироваться.
- Должен соблюдаться закон 152-Ф3
- Контроль доступа на основе ролей (RBAC)
- Должен соблюдаться принцип наименьших привилегий.
- Логирование действий. Логи не должны содержать чувствительную информацию и должны быть зашифрованы.


### Протоколы аутентификации и авторизации

- Для авторизации и аутентификации пользователей должен использоваться протокол OpenID Connect.

### Описание взаимодействия между системами предприятия и внешней платформой.

1. Собственник подключает услугу умный дом в tenant-core-app.
2. Tenant-core-app включает умный дом для пользователя и передает идентификатор дома в smart-home-app
3. Smart-home-app связывает устройства с пользователем.
4. Собственник регистрирует биометрию и номер автомобиля в smart-home-app.
5. Smart-home-app токенезирует данные пользователя и передает биометрию во внешнюю систему партнера.
6. Когда внешняя система умный дом распознает пользователя, она передает токен пользователя и токен устройства в приложение smart-home-app.
7. Smart-home-app проверяет токен пользователя, проверяет привязку пользователя к устройству и наличие оплаченной услуги.
8. Если пользователь распознан и услуга активна, то отправляется команда подтверждения в противном случае отказ.
